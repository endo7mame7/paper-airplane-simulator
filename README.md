# paper-airplane-simulator

折り紙で作った紙飛行機を、できるだけ遠くまで飛ばすシミュレーターゲーム（開発中）。

## あそびかた

起動するとメインメニューが出ます。

1. **✎ 紙飛行機を折る**：紙の上をドラッグして折り線を引き、折りたい側をクリック（谷折り・山折り・折り筋・中割り折り、全部の層 / 上だけ）。右の「飛行機としての性能」で飛びそうか確かめられます。見本は「紙飛行機」「やり飛行機」
2. **✈ 飛ばす**：準備画面（FLIGHT CHECK）で、性能の★と予想飛距離、コースの風を確認して「コースへ」。ローディング画面では、飛ばすコツや折り紙の豆知識が読めます
3. **投げる**：ボタン（`Space`）を 3 回。振りかぶる → 強さを決める → 白い「ジャスト」で投げる
4. **記録**：投げるたびに記録され、上位 10 件がランキングに残ります。結果の「▶ リプレイ」（`P`）で、投げた 1 投をスローでも見直せます
5. **🔬 分析**：投げた結果から分析モードへ。空気の流れ・翼の圧力・力の矢印を 3D で見ながら、飛距離が伸びなかった理由と直し方を確認できます（揚力線理論による簡易モデル）

メニューの「✈ 見本ですぐ飛ばす」なら、折らずにすぐ準備画面へ行けます。

## 構想

1. 折り紙シミュレーターで紙飛行機を折る
2. コースで、人が紙飛行機を投げて飛ばす
3. どこまで飛んだか（飛距離）を記録する

## 進み具合

- [x] 折り紙シミュレーターを取り込む
- [x] 折った形から、飛行機としての性能（重さ・重心・翼の面積・安定性など）を計算する（`js/aero.js`、画面右の「飛行機としての性能」）
- [x] 性能から、飛ぶ様子を計算する（`js/flight.js`）
- [x] コースで、投げる角度と強さを決めて投げる（「✈ 飛ばす」。3D のコースで、タイミングよくボタンを押して投げる）
- [x] 飛距離を記録する（ランキング上位 10 件、折り方も保存して呼び出せる）

### 飛行機としての性能（`js/aero.js`）

`analyzeAirplane(state, options)` に折り紙シミュレーターの状態を渡すと、次の値を返します（単位は m・kg・度）。

| 値 | 内容 |
|---|---|
| `mass`, `cg` | 重さと重心。重なった紙はその枚数分重い |
| `wingArea`, `span`, `length`, `mac`, `aspectRatio`, `wingLoading` | 真上から見た形（平面形）の面積・翼幅・全長・平均翼弦・縦横比・翼面荷重 |
| `cgFromNose`, `acFromNose`, `staticMargin` | 機首から重心・空力中心までの距離と静安定余裕（正なら機首が重くて安定） |
| `dihedral` | 上反角（翼端が上がっていれば正） |
| `sideArea` | 横から見た面積（胴・キール） |
| `symmetry`, `wingBalance`, `lateralOffset` | 左右の対称性とずれ |
| `axes` | 自動で判定した機体の向き（上・前・右） |

紙の実寸は、正方形は 15cm 角、A4 比は長い辺 29.7cm として計算しています（坪量 70g/m²）。

### 飛行シミュレーション（`js/flight.js`）

`simulateThrow(aero, { speed, angle, height, yaw, bank }, { wind, dt, maxTime })` に `analyzeAirplane` の結果と投げ方を渡すと、地面に落ちるまでを計算して `{ distance, time, maxHeight, lateral, path }` を返します。`path` は 1/60 秒ごとの位置と姿勢です。

- 重心の 3 次元の動き、ピッチ（機首の上下）、バンク（左右の傾き）を計算します。機首は、胴（キール）のはたらきで進む向きにそろうものとします
- 機首が重すぎると落ちやすく、後ろが重すぎると失速しやすくなります。翼の後ろのふちを少し上げる（昇降舵）と長く滑空し、片方だけ上げると曲がります
- 見本の紙飛行機（15cm 角）を 8 m/s で投げると、約 10〜12 m 飛びます

### 飛ばす画面（`js/course.js`, `js/swing.js`）

画面上の「✈ 飛ばす」（`Tab`）で、折った紙飛行機を 3D のコースで投げます。

- ボタン（`Space` か画面のタップ）を 3 回押して投げます
  1. 振りかぶる：カーソルが右（強さ 100%）へ動く
  2. 強さを決める：カーソルが左へ戻ってくる
  3. 白い「ジャスト」で押す：狙いどおりに投げられる。早い・遅いと左右にそれて傾き、力も逃げる
- 投げるたびに記録され、ランキング（🏆、`R`）に上位 10 件が残ります。記録はこのブラウザの中だけに保存されます
- コースには風が吹いていて、投げるたびに変わります（左上の矢印と吹き流しで確認。`W` で風なしにもできる）
- `↑` `↓` で投げる角度、`←` `→` で向き、`C` でカメラ（後ろから / 横から）、飛行中の `Space` で着地まで飛ばす

## 折り紙シミュレーター

バージョン 1.3.0（変更内容は [CHANGELOG.md](CHANGELOG.md)）

ブラウザで紙を折って遊べる 3D 折り紙シミュレーターです。ビルド不要で、静的ファイルだけで動きます（three.js は `vendor/` に同梱）。

### 起動

ES Modules を使うため、ローカルサーバー経由で開いてください。

```sh
npm start            # = python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages などにそのまま置いても動きます。

### できること

画面の下のツールバーで、折り方をいつでも切り替えられます。

- **線を引いて折る**：紙の上をドラッグして折り線を引き、折りたい側をクリック
- **点を重ねて折る（点→点）**：動かしたい点（角など）を重ねたい点までドラッグ（その 2 点の垂直二等分線で折る）
- **谷折り / 山折り**
- **折り筋**：折ってすぐ開き、筋だけを残す。筋は紙の上に表示され、筋の端・交点・筋の線上に吸い付くので、筋を目印に折れる
- **袋をつぶす（つぶし折り）**：2 枚が折り目でつながった袋のつけ根に線を引き、袋をクリック。袋を開いて左右対称につぶす（正方基本形などが作れる）
- **中割り折り**：袋の途中に線を引き、先の側をクリック。先を内側に折り込む
- **花弁折り**：正方基本形の 1 枚目に、花弁のつけ根の横線を引き、下の角の側をクリック。下の角を持ち上げ、左右を内側に折り込む（鳥の基本形が作れる）
- **全部の層 / 上だけ**：上だけのときは、クリックした所の一番上の部分と、その上に乗っている紙を一緒に折る（紙を突き抜けない）
- 角・辺の中点への吸い付き、`Shift` で 22.5° 単位の角度固定
- 折るときのアニメーション、元に戻す / やり直す、裏返す、90° 回す
- **手順ごとの開き具合スライダー**：途中まで開いた立体的な形も作れる
- 最初から再生、すべて開く / たたむ、手順をクリックしてその段階を表示
- **展開図**（山折り＝赤の一点鎖線、谷折り＝青の破線）を自動で表示
- 見本：三角、紙飛行機、屏風折り（扇）、たこ形、兜（かぶと）、セミ、鶴
  - 鶴は、正方基本形 → 花弁折り → 鳥の基本形 → 中割り折りで首・尾・頭 → 羽、と実際の手順どおりに折ります
- **BGM**：Web Audio でその場で作る和風の音楽（都節音階の琴の音＋持続音）。音楽ファイルは使っていません
- 紙の形（正方形 / A4 比 / 1:2）、表裏の色、模様（無地・方眼・青海波・水玉）
- マウス（右ドラッグで視点回転、ホイールで拡大）とタッチ（2 本指で回転・拡大）に対応

### しくみ

- `js/paper.js` … 描画に依存しない幾何モデル。紙を凸多角形の面の集合として持ち、
  折り線で面を分割 → 動く側を鏡映 → 重なり順（layer）を更新します。
  各面は「自分を動かした手順」を覚えていて、手順ごとの角度で回転を合成して 3D の姿勢を求めます。
  展開図の山・谷は、隣り合う面の向きと重なり順から求めます。
- `js/main.js` … three.js による表示と操作（入力、アニメーション、UI）
- `js/presets.js` … 見本の折り方
- `js/bgm.js` … BGM（Web Audio API）

### 制限

平らに折る「単純な折り」（すべての層、または一番上／下のつながった部分を 1 本の直線で折る）を組み合わせて形を作ります。
つぶし折り・中割り折り・花弁折りは、紙の各部分を折り線で折り返す動きの組み合わせとして計算しています。
折った結果は、紙が破れていないか（展開図で隣り合う面が、折った後もつながっているか）を検査しています。
途中のアニメーションでは、紙が一瞬重なって見えることがあります。沈め折りには対応していません。
