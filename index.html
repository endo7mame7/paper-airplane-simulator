        使い方

        • 線：紙の上をドラッグして折り線を引き、折りたい側をクリック。
        • 点→点：動かしたい点（角など）を、重ねたい点までドラッグ。
        • 折り筋：折ってすぐ開き、筋だけ残します。筋の端・交点・筋の上にも吸い付きます。
        • 中割り：袋の途中に線を引いて、先の側をクリック。先を内側に折り込みます。
        • 上だけ：クリックした所の一番上の部分を折ります。その上に乗っている紙も一緒に折れます（紙を突き抜けないように）。
        • 角や辺の中点には自動で吸い付きます。Shift で角度を 22.5° 単位に。
        • 右ドラッグ／2 本指で視点を回転、ホイール／ピンチで拡大縮小。
        • L 線 / P 点→点 / V 谷 / M 山 / C 折り筋 / I 中割り
        • A 全部の層 / T 上だけ / F 裏返す / R 回す / B BGM / Esc 取り消し

        紙飛行機シミュレーター

        折って、投げて、どこまで飛ぶ？

        あそびかた

        1. 折る：紙の上をドラッグして折り線を引き、折りたい側をクリック。右の「飛行機としての性能」で飛びそうか確かめよう。翼の開き具合は「手順」のスライダーで変えられる。
        2. 飛ばす：「✈ 飛ばす」で準備画面へ。性能を確かめて「コースへ」。
        3. 投げる：ボタン（Space）を 3 回。振りかぶる → 強さを決める → 戻ってくるカーソルを白い「ジャスト」で止める。
        4. 風：左上の矢印が風の向き。追い風は遠くへ、向かい風は手前に、横風は流される。
        5. 記録：投げるたびに記録され、上位 10 件はランキングに残る。ランキングから、その紙飛行機を呼び出せる。

        コツ：機首が重すぎると落ち、後ろが重いと失速する。翼が少し上向き（上反角）だとまっすぐ飛ぶ。
